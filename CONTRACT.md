# CONTRACT overlay — zistgah/paradox

Thin overlay on the master contract at `zistgah/governance`. It ADDS; it never relaxes.

1. **The plates are canonical.** A defect found later becomes a NEW plate and a new version, never an
   edit to a published one.
2. **Preserve the hedging.** Panels marked hypothesis or correlation are reproduced as such. A
   summary that promotes either to an established finding is a contract violation, not a tidy-up.
3. **Preserve the primitives.** Inclination ≠ gradient ≠ probability ≠ intent ≠ act ≠ execution.
   Collapsing any of these in derived text or metadata is ontological substitution.
4. **No vendor name in any text layer** — titles, slugs, config, metadata, overlays.
5. **`assets/figures` is data.** Only declared figures plus the cover may live there; the seeder's
   contract check refuses anything undeclared, because an undeclared file WILL be minted.
6. **Nothing pushes or mints without his typed gate.** An AI writes the script; he runs it.
7. **The tool's interface is read, never recalled** — and a discovered verb is not a discovered
   signature (`misty ots stamp <path>`, one path, no globs).
